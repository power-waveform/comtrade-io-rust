Expand description

发电机（规范 §1.6 [ZYHD POWER_#n]）

Fields§

§idx: usize

设备序号（INF DEV_ID）

§name: String

设备名称（INF DEV_ID）

§src_ref: String

源引用（DMF srcRef）

§sys_id: String

INF SYS_ID

§trm_id: String

INF TRM_ID=idx,name，相关主变。原文存储以保 round-trip。

§object_type: String

发电机类型（INF OBJECT_TYPE）：STEAM_TURBINE = 气轮机，WATER_TURBINE = 水轮机

§freq: f64

额定频率（Hz）

§capacity: f64

额定容量（MW）。注意与变压器 CAPACITY（MVA）单位不同。

§factor: f64

功率因数

§v1: f64

一次额定电压（kV）

§branch_num: BranchNum

中性点分支数（3 元组）

§rotor_i: f64

转子电流额定值（A）

§rotor_v2: f64

转子分流器二次额定值（mV）

§ufe: Ufe

励磁电压（2 元组，V）

§x: SyncReactance

同步电抗（4 元组，标么值）

§excitation_mode: i32

励磁方式（0=励磁变，1=励磁机，2=励磁变+励磁机）

§igt_dir: i32

机端电流方向（0=流出发电机，1=流入发电机）

§acv: AcvChn

机端电压 TV 通道（TV_CHNS=Ua, Ub, Uc，仅 3 字段，un_idx 恒 0）

§ta: AccBran

机端电流 TA 通道（TA_CHNS=Ia, Ib, Ic, 极性）

§ta_z1: AccBran

中性点第一分支组 TA（TA_Z1_CHNS）

§ta_z2: AccBran

中性点第二分支组 TA（TA_Z2_CHNS）

§ta_z3: AccBran

中性点第三分支组 TA（TA_Z3_CHNS）

§ufe_chns: UfeChns

励磁电压通道（3 元组）

§ife_chn: usize

励磁电流通道（Ife_CHN=Ife）

§un_chns: UnChns

机端零序电压通道（3 元组）

§ta_ido_chn: usize

零序横差 TA 通道（TA_Ido_CHN=Ido）

§oth_achns: Vec<usize>

其他相关模拟量通道（OTH_ACHNS）

§sta_chns: Vec<usize>

开关量通道（STATUS_CHNS）
