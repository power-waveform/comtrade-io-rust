Expand description

交流电流分支（DMF ACC_Bran / INF TA_CHNS TA_Id_#N）

dir 语义按规范 §1.4：1 = 正方向（流向线路），-1 = 反方向，缺省 1。 变压器侧（§1.5）该值为极性符号：1 = 电流流入变压器，-1 = 流出。

dir_raw 保留 DMF 原始拼写（样本中 POS / pos 大小写不一致）， 以便 round-trip 时按原文写回；dir 是归一化后的语义值。
